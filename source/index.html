    sidePanel
    全部界面都显示在浏览器侧边栏里。The whole interface lives in the side panel.
    tabs
    读取标签页的标题、网址和图标来列出它们,并执行切换、移动、关闭、新建。Listing tabs (title, URL, icon) and switching, moving, closing and opening them.
    storage
    在本地保存空间、收藏夹、固定标签、别名,以及重启后恢复用的标签页状态。Saving spaces, favorites, pinned tabs, aliases and tab state for restoring after a restart.
    favicon
    显示收藏夹和固定标签的网站图标。Showing site icons for favorites and pinned tabs.
    search
    在搜索栏输入关键词回车时,用浏览器的默认搜索引擎搜索。Searching with your default engine from the search box.
    clipboardWrite
    「复制链接地址」时把网址写入剪贴板,不读取剪贴板。“Copy link address”. The clipboard is never read.
    sessions
    撤销「关闭标签页」时,从最近关闭的记录里恢复它。Restoring closed tabs on undo.
    history
    搜索时列出最近 30 天里匹配的网页,点 × 删掉某一条;「不记录历史」的空间和文件夹里,删除刚从里面访问的网址。只在本地读,不上传。Listing matching pages from the last 30 days when you search, deleting one with ×, and removing the pages just visited from no-history spaces and folders. Read locally, never sent anywhere.
    webNavigation
    判断新标签页是不是从某个页面里的链接打开的(子标签),以及它的地址是否已经打开(相同地址只开一份)。Telling whether a new tab was opened from a link on a page (child tabs) and whether its address is already open (no duplicate tabs).
    tabGroups
    把每个空间显示成顶部标签栏里的一个标签页分组,切换空间时折叠其他空间的分组。Showing each space as a tab group in Chrome's tab strip and collapsing the other spaces.

    三步装上Three steps to install

    推荐从源码安装:零依赖,仓库就是插件本身。Install from source: zero dependencies, the repository is the extension.

    1. 克隆仓库Clone the repository

      不用 git 的话,也可以从 Releases 下载 zip 解压。No git? Download the zip from Releases and unzip it instead.

      git clone https://github.com/winzipsdo/sidearc.git

    2. 加载扩展Load it

      打开这个地址,开启「开发者模式」,点「加载已解压的扩展程序」,选择仓库文件夹。Open this address, turn on Developer mode, click “Load unpacked” and choose the repository folder.

      chrome://extensions

    3. 打开侧边栏Open the sidebar

      点工具栏上的 Sidearc 图标,或者按快捷键:Click the Sidearc toolbar icon, or press:

      Alt+SWindows / Linux⌥ Option+SMac

    需要 Chrome 116 或更高版本。暂时还没上架应用商店。Requires Chrome 116 or later. Not on the Chrome Web Store yet.

    更新:在仓库里 git pull,把侧边栏关掉再打开,就是最新版本。少数更新改到了后台(background.js 或 manifest.json),到 chrome://extensions 点一下 Sidearc 的刷新按钮;拿不准时点一下也没坏处,空间、收藏和设置都还在。 Updating: run git pull in the repository, then close and reopen the sidebar. The few updates that touch the background (background.js or manifest.json) also need the reload button on Sidearc's card in chrome://extensions; if unsure, reloading is harmless and keeps your spaces, favorites and settings.

    按自己的习惯改:代码是原生 JS/CSS,不用编译。哪里用着不顺手,直接让 AI 编程助手(比如 Claude Code)在仓库里改,比如「行再紧凑一点」;改完关掉再打开侧边栏就能看到效果。 Make it yours: the code is plain JS/CSS with nothing to compile. If something doesn't fit how you work, ask an AI coding assistant (such as Claude Code) to change it in the repository, say "make the rows more compact", then close and reopen the sidebar to see it.

    想让侧边栏像 Arc 一样在左边? 打开 chrome://settings/appearance,把「侧边栏位置」改为「显示在左侧」。这是 Chrome 自己的设置,扩展无法代为修改。 Want the sidebar on the left, like Arc? Open chrome://settings/appearance and set the side panel position to left. It's Chrome's own setting, so the extension can't change it for you.
