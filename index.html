先上手

下面不是录像，是插件本身的代码，跑在一个模拟的 Chrome 里。照着清单试几件事，做到哪条，哪条自己勾上。

试试这几件事 0/9 都做完了。喜欢的话，装上。

    三件要紧的事

    竖着排只是开始。这三件，是它的脾气。

    其一

    不是第二份列表，是同一份

    Chrome 自己的标签栏跟着侧边栏走：在哪边拖，另一边都跟着动。你自己建的分组原样保留。

    其二

    工作、学习、生活，各有一套

    每个空间有自己的标签页和主题色，在顶部就是一个分组。点折叠的分组或底部圆点，整个侧边栏就切过去。

    其三

    该关的，自己会冒出来

    久不去看的标签页，自会落上几片叶子：离开满一天落第一片，越久越多。随手一扫就干净，点进去就吹走。

    还有这些

    都是小事，天天用得上。带「试试」的，上面的试用里就能做。

    子标签
    从哪个页面点开的，就挂在哪下面。
    固定标签
    关了也留着入口；跑远了，点 ↩ 一键回家。
    收藏夹
    所有空间共用的一排图标，最常去的放这里。
    按域名整理
    一键把同一个网站的标签页排到一起，不关任何一个。
    只开一份
    已经开着的网址，直接切过去。
    撤销
    关错了、拖错了，Ctrl/⌘+Z 一步步撤回。
    休眠
    一键卸掉内存；音乐、聊天可以保持唤醒。
    键盘
    方向键移动选中框，回车打开。
    多选
    点选一批，一起拖、一起关、一起换空间；固定标签也行。
    拆分视图
    并排看的两个标签页在侧边栏里合成一块，拖动不拆散。
    足迹
    刚离开的标签页留一道慢慢消失的竖条。
    搜索
    按 /，标签页和最近的历史记录一起搜。

    此外还有别名、文件夹、不记录历史的空间、复制成 Markdown、最近关闭、恢复上次的标签页、浅色与深色、可以换成今楷的字体、中文与 English。功能详解

    安装

    从源码装：零依赖，仓库就是插件本身。需要 Chrome 116 或更高版本，暂时还没上架应用商店。

    # 一、克隆仓库。不用 git 的话，从 Releases 下载 zip 解压也一样

    git clone https://github.com/winzipsdo/sweeping-monk.git

    # 二、打开扩展页，开启「开发者模式」，点「加载已解压的扩展程序」，选仓库文件夹

    chrome://extensions

    # 三、点工具栏上的「赭」图标，或者按快捷键

    Alt+S Windows / Linux

    ⌥ Option+S Mac

    从 Releases 下载 zip

    更新
    在仓库里 git pull，把侧边栏关掉再打开，就是最新版本。少数更新改到了后台，到 chrome://extensions 点一下「赭」的刷新按钮；拿不准时点一下也没坏处，空间、收藏和设置都还在。
    按自己的习惯改
    代码是原生 JS/CSS，不用编译。哪里用着不顺手，直接让 AI 编程助手在仓库里改，比如「行再紧凑一点」；改完关掉再打开侧边栏就能看到。
    放到左边
    想让侧边栏在左边，打开 chrome://settings/appearance，把「侧边栏位置」改为「显示在左侧」。这是 Chrome 自己的设置，扩展没法代为修改。

    快捷键

    打开侧边栏的那一个，可以在 chrome://extensions/shortcuts 里改。

    数据只在本机

    不收集，不上传，没有统计，没有第三方脚本。一切都留在你的浏览器里，卸载即删除。

    每项权限用来做什么，都写在这里。 完整的隐私政策

    只有一处会联网，而且要你自己点：在设置里把字体换成「今楷」时，它从这个网站下载一次字体文件，存在本机，之后不再联网。

    sidePanel
    全部界面都显示在浏览器侧边栏里。
    tabs
    读取标签页的标题、网址和图标来列出它们，并执行切换、移动、关闭、新建。
    storage
    在本地保存空间、收藏夹、固定标签、别名，以及重启后恢复用的标签页状态。
    favicon
    显示收藏夹和固定标签的网站图标。
    search
    在搜索栏输入关键词回车时，用浏览器的默认搜索引擎搜索。
    clipboardWrite
    「复制链接地址」时把网址写入剪贴板，不读取剪贴板。
    sessions
    撤销「关闭标签页」时，从最近关闭的记录里恢复它。
    history
    搜索时列出最近 30 天里匹配的网页；「不记录历史」的空间里，删除刚访问的网址。只在本地读，不上传。
    webNavigation
    判断新标签页是不是从某个页面里的链接打开的，以及它的地址是否已经开着。
    tabGroups
    把每个空间显示成顶部标签栏里的一个分组，切换空间时折叠其他空间的分组。

    名字

    标签页开多了，心也跟着乱。「赭」让它们各安其位；久不去看的，自会落上几片叶子，随手一扫，地净，心也净。

    赭，读 zhě，是红褐色，图标那枚印的颜色；印上刻的是一个人在扫落叶，英文名 Sweeping Monk 说的也是他。它曾叫 Sidearc 和扫地僧，2026 年 11 月改成现在的名字；空间、收藏和设置都原样带了过来。

    问答

    「赭」是什么？
    一个免费开源的 Chrome 扩展：把标签页竖着排进浏览器自带的侧边栏，按空间分开，和顶部的标签栏双向同步。
    会动我顶部的标签栏吗？
    会，而且是有意的：顶部的顺序始终和侧边栏一致，收藏在最左边，每个空间一个分组。你自己建的分组原样保留。
    为什么不在应用商店？
    还在打磨，暂时只从源码或 Releases 的 zip 安装。从源码装的，更新只要一句 git pull。
    能改成自己的样子吗？
    能。代码是原生 JS/CSS，不用编译，以 MIT 许可证发布，改完重新打开侧边栏就生效。
