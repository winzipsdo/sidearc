Arc 风格的 Chrome 侧边标签栏:子标签、空间、固定标签和收藏夹。它不替换 Chrome 自己的标签栏,而是让两边始终一致:每个空间就是顶部的一个标签页分组,在哪边拖动,另一边都跟着变。

    1 分钟看懂 Sidearc

    双向同步

    侧边栏和顶部标签栏,始终是同一份顺序

    大多数垂直标签栏插件只是另画一份列表。Sidearc 让 Chrome 自己的标签栏跟着它走:收藏的标签页在最左边,然后每个空间一个分组,组内先固定标签、再列表,子标签紧跟父标签。

    • 在侧边栏里拖,顶部跟着变;在顶部拖,侧边栏也跟着变
    • 在顶部把标签页拖进别的空间的分组,就是移到那个空间
    • 你自己或别的扩展建的分组原样保留

    空间

    工作、学习、生活,各有一套标签页

    每个空间有自己的主题色、固定标签和标签页,整个侧边栏跟着变色。顶部标签栏里每个空间是一个分组:当前空间展开,其他折叠成一个小标签;点开它,侧边栏就切过去。

    • 底部圆点一键切换,把标签页拖到圆点上就是换空间
    • 「不记录历史」的空间和文件夹:访问过的网址立刻从历史里删掉

    子标签与固定标签

    从哪打开就挂在哪下面;固定标签记得回家的路

    网页里点开的链接自动缩进到原标签页下面,关掉父标签页时一起关。固定标签点进了别的页面,这一行会显示它现在在哪,点 ↩ 一键回到固定的地址;当前页面还能另存成新的收藏或固定标签。

    • 给标签页起个别名,显示在标题前,搜索也能搜到
    • 固定标签可以分文件夹,收藏夹所有空间共用
    • 点空间名把固定标签整个收起来,只留正在看的那个
    • 开在另一个窗口里的收藏和固定标签会标出来

    还有这些小心思

    落叶 1.8

    很久没进去过的标签页会慢慢落上叶子:离开一天后开始落,之后每 12 小时一片(可以调),提醒你它也许可以关了。鼠标左右扫几下就扫干净,点进去叶子被风吹走。

    足迹

    最近离开的几个标签页(默认 3 个,设置里可以改)左边有一道主题色竖条,10 分钟里慢慢缩短、变淡,刚才在看的页面一眼就能找回来。

    休眠

    点月亮让标签页从内存里卸掉,标签还在;行尾标着睡了多久。文件夹、空间可以一起休眠,音乐和聊天可以设成「保持唤醒」。

    键盘操作

    点一下侧边栏,方向键移动一个 Switch 风格的选中框,回车打开、Delete 关闭、Shift+F10 打开右键菜单。

    相同网址只开一份

    打开一个已经开着的网址,直接切到那个标签页;是收藏或固定过的,就用那个收藏打开。特意新开的(Ctrl/⌘+点击)不合并。

    什么都能撤销

    关闭、清理、取消固定、从收藏移除,都能按 Ctrl/⌘+Z 一步步撤销;在顶部标签栏关掉的也能找回。左下角还有最近关闭的列表。

    多选

    Ctrl/⌘+点击多选、Shift+点击连选,和顶部标签栏的选择同步;拖一个就一起移动,右键一起关闭、休眠或换空间。

    恢复上次的标签页

    Chrome 启动时没有恢复上次的标签页,侧边栏会提醒,一点就按原来的空间、层级和别名开回来。左下角还有最近关闭的列表。

    创建副本、硬性重新加载

    收藏和固定标签可以就地创建副本;右键菜单里有不走缓存的「硬性重新加载」。关掉当前标签页,会回到刚才所在的那个。

    三步安装

    需要 Chrome 116 或更高版本。暂时还没上架应用商店。

    1. 下载并解压

      从 Releases 下载最新的 sidearc-版本号.zip 并解压。想跟着最新代码走,也可以克隆仓库。

      打开 Releases

    2. 加载扩展

      打开下面的地址,开启右上角的「开发者模式」,点「加载已解压的扩展程序」,选择解压出的文件夹。

      chrome://extensions

    3. 打开侧边栏

      点工具栏上的 Sidearc 图标,或者按快捷键:

      Alt+SWindows / Linux⌥ Option+SMac

    想让侧边栏像 Arc 一样在左边? 打开 chrome://settings/appearance,把「侧边栏位置」改为「显示在左侧」。这是 Chrome 自己的设置,扩展无法代为修改。

    不联网,数据只在本机

    Sidearc 不收集、不上传任何数据,代码里没有网络请求,也没有统计或第三方脚本;纯原生 JS/CSS,没有依赖,也没有构建步骤,每一行都能直接读。空间、收藏夹、固定标签和别名都保存在浏览器本地,卸载扩展即删除。

    每项权限用来做什么
    sidePanel
    全部界面都显示在浏览器侧边栏里。
    tabs
    读取标签页的标题、网址和图标来列出它们,并执行切换、移动、关闭、新建。
    storage
    在本地保存空间、收藏夹、固定标签、别名,以及重启后恢复用的标签页状态。
    favicon
    显示收藏夹和固定标签的网站图标。
    search
    在搜索栏输入关键词回车时,用浏览器的默认搜索引擎搜索。
    clipboardWrite
    「复制链接地址」时把网址写入剪贴板,不读取剪贴板。
    sessions
    撤销「关闭标签页」时,从最近关闭的记录里恢复它。
    history
    只用于「不记录历史」的空间和文件夹:删除刚从里面访问的网址,不读取其他历史。
    webNavigation
    判断新标签页是不是从某个页面里的链接打开的(子标签),以及它的地址是否已经打开(相同地址只开一份)。
    tabGroups
    把每个空间显示成顶部标签栏里的一个标签页分组,切换空间时折叠其他空间的分组。
