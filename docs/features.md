# Sidearc 功能详解

简体中文 | [English](features.en.md) | [返回 README](../README.md)

每个功能的完整行为和细节。快捷键见 README 的[快捷键与操作](../README.md#快捷键与操作)。

## 标签页

- **垂直标签栏**:点击切换,中键或 ✕ 关闭,拖拽排序;正在发声的标签可一键静音(收藏和固定标签也会显示)。
- **多选**:`Ctrl/⌘+点击`选中多个标签页,`Shift+点击`连选,和顶部标签栏的多选同步;拖动其中一个就一起移动,右键其中一个可以一起关闭、休眠或移到别的空间,按 Delete 一起关闭。点空白处或按 Esc 取消。
- **回到当前标签页**:列表滚动后当前标签页看不见了,它在哪一边(上面或下面),列表那一边就浮出一个带它图标和箭头的小胶囊,点一下滚回去、让它停在中间并亮一下。它露出一点就收起;搜索时不出现。
- **和顶部标签栏同步**:顶部原生标签栏的顺序始终和侧边栏一致:收藏的标签页在最左边,然后每个空间一个分组,组内先固定标签、再列表,子标签紧跟父标签。
  - 在侧边栏里拖动,顶部跟着变;在顶部拖动,侧边栏也跟着变。
  - 在顶部把标签页拖进别的空间的分组,就是移到那个空间;把子标签拖离父标签,它就不再是子标签。
- **拆分视图**:用 Chrome 的拆分视图(Split View)并排看两个标签页时,侧边栏里这两个标签页挨在一起、合成一块浅底,正在看的那个照常是白卡片。拖动、移到别的空间、拖进别的标签页当子标签时两个一起走,不会把拆分视图拆开;往这一对中间放标签页会放到这一对前面。当前标签页在拆分视图里时,和它在一起的那个不算多选。需要 Chrome 140 以上。Chrome 155 以上还可以在侧边栏里操作:多选两个标签页后右键选「在拆分视图中打开」(不挨着会先挪到一起,然后切过去),或者右键一个标签页选「与当前标签页拆分视图」,和正在看的那个拼在一起;也可以把一个标签页拖到另一行的右半边(会出现写着「拆分视图」的虚线框),松手后两个并排;右键拆分视图里的任意一个,选「反转视图」把两边对调,选「取消拆分视图」把两个分开、都留在原地。菜单里的叫法和 Chrome 自己的一样(「与当前标签页拆分视图」是 Chrome「使用当前标签页创建新的拆分视图」的简写)。
- **子标签**:在网页里点链接开出的新标签页,会自动缩进显示在原标签页下面。
  - 也可以手动归组:把标签页拖到另一个标签页上。
  - 移出:拖到别处,鼠标移到子标签上点关闭按钮左边的移出按钮;右键父标签选「解除所有子标签」可一次全部移出。
  - 最多两级,从子标签里打开的会和它并列;关闭父标签页会连同子标签一起关闭。从收藏或固定标签里打开的页面不做子标签,直接是顶级标签页,再从它打开的页面才挂在它下面。
  - 从其他应用(比如聊天软件)点开的链接、新建的标签页不算子标签。
- **别名**:右键标签页或固定项设置,显示在标题左侧,搜索也会匹配。
- **相同地址只开一份**:新开的标签页如果和本窗口同一个空间里已有的标签页地址相同(忽略 `#` 锚点),会直接切到已有的那个并关掉新开的,侧边栏也滚到它那里并让它亮一下;如果地址和某个还没打开的收藏或本空间的固定标签相同,新开的标签页会直接成为它的标签页,显示在收藏夹或固定标签里。Chrome 自带的「复制标签页」和恢复关闭的标签页不受影响。从网页里特意新开的标签页(`Ctrl/⌘+点击`、鼠标中键、在新标签页打开的链接)不合并,地址重复也照样单独打开。
- **足迹**:最近离开的几个标签页(默认 3 个)左边有一道主题色竖条(收藏在图标下面一道短横线),每道线各自倒计时 10 分钟,从两头往中间缩短、同时变淡,到时间就消失,方便找回刚才在看的页面;和正在看的标签页拼在同一个拆分视图里的不算离开,不画。显示几个(不显示、1、3、5、10 个)在右下角的设置里选。
- **落叶**:很久没进去过的标签页,行尾慢慢落上叶子:离开满一天落第一片,之后每过 12 小时再落一片,最多 12 片,一眼看出哪些可以关了。鼠标在上面左右来回扫几下就扫干净(重新计时,不打开它);点进去叶子被吹走。也可以右键标签页选「撒落叶」,在现有的基础上随机再落 1 到 6 片(一样最多 12 片;之后按时间该落的片数追上来了才会再多);正在看的标签页也能撒,离开再点回来时才被吹走;多选时每个各撒各的。多久落一片(不落、6、8、12 小时)在右下角的设置里选。
- **键盘操作**:点一下侧边栏后按方向键,从当前页面开始移动选中框(样式和动效参考 Switch),回车打开、Delete 关闭;具体按键见[快捷键与操作](../README.md#快捷键与操作)。
- **搜索**:平时收成空间名右边的放大镜(鼠标移到顶部时出现),点它或按 `/`、`Ctrl/⌘+F` 展开;输入即过滤;回车跳到第一个匹配项,没有匹配时打开网址或用默认搜索引擎搜索。输入两个字以上,下面还会列出最近 30 天里匹配的历史记录(先列 8 条,更多的点末尾「再显示 N 条」展开,最多 50 条;已经开着的不重复),点一下打开,点叉号从历史记录里删掉。
- **批量关闭**:「清理」一键关闭当前空间里除当前页以外的未固定标签页;右键标签页可「关闭下方标签页」。

## 收藏夹、固定标签与空间

- **收藏夹**:顶部的图标网格,所有空间共用,不随下面的列表滚动(空间名那一行也是)。把标签页拖进去即可添加。
- **固定标签**:每个空间一组。关闭标签页后固定项仍保留,再点会重新打开。鼠标移上去时,右侧有一个按钮:标签页开着时是「−」,只关闭标签页、保留固定;没开着时是带斜线的图钉,点了取消固定(可撤销)。收藏和固定标签的名称会跟着网页标题更新,在「编辑」里手动改过名称的除外。它们的标签页开在别的窗口里时,会标一个带往外箭头的小窗口图标,点了会跳到那个窗口。
  - 开着的固定标签点进了别的页面时,这一行显示当前页面,前面标着固定的名字;点右边的 ↩ 回到固定的地址。收藏也一样:点进了别的页面时,图标换成当前页面的,鼠标移上去时右上角的关闭按钮变成 ↩,先回到收藏的地址,回去之后才是关闭。右键菜单的「当前页面」一组里还可以把它「加入收藏夹」或「固定」(另存一个新项,当前标签页和原来的固定标签都不变),或者「替换原来的固定地址」。
  - **折叠**:点空间名可以把这个空间的固定标签整个收起来(每个空间各记各的),只留正在看的那个;空间名后面标着里面开着几个标签页。拖标签页到空间名上时会临时展开,方便拖进去。
  - **文件夹**:空间菜单(空间名右边的「⋯」)里选「新建文件夹…」,或右键固定标签「新建文件夹并移入…」。把固定标签或下面列表里的标签页拖到文件夹上就放进去,拖出来或右键「移出文件夹」就移出;点文件夹折叠/展开,右键可重命名,也可以一键关闭(或休眠)里面所有开着的标签页,固定标签都留着,关闭可撤销。删除文件夹时里面的固定标签会一起删掉(开着的标签页会留在下面的列表里),可撤销。
  - **不记录历史的文件夹**:右键文件夹开启后,从它里面打开的页面(包括之后点进的其他页面)访问后会立刻从浏览历史中删除;和「不记录历史的空间」一样,不是无痕模式。
- **空间**:底部圆点切换,每个空间有自己的主题色、固定标签和标签页。把标签页拖到圆点上可移到别的空间。顶部标签栏里每个空间是一个标签页分组:当前空间展开,其他空间折叠成一个带名字的小标签,点开就切到那个空间。窗口里只有一个空间的标签页时也照样分组。
- **不记录历史的空间**:右键空间圆点开启后,在该空间里访问的网址会立刻从浏览历史中删除。这不是无痕模式:Cookie、登录状态、缓存和下载记录照常保留。

## 其他

- **撤销**:关闭标签页、清理、关闭下方标签页、取消固定、从收藏夹移除、相同地址的自动切换,都可以点底部提示条的「撤销」或按快捷键撤销,可连续撤销多步。在 Chrome 自己的标签栏里关掉的标签页,在侧边栏里按快捷键也能恢复,和其他操作按先后顺序一起撤销。
- **关掉后回到刚才的标签页**:在侧边栏里关掉正在看的标签页(行上的关闭按钮、右键「关闭」、键盘 Delete)时,会回到刚才所在的那个标签页,而不是跳到它后面的;比如在 A 里点开了 B,关掉 B 就回到 A,连着关就一路往回走。在顶部标签栏里或按 `Ctrl/⌘+W` 关的,仍按 Chrome 自己的规则。
- **最近关闭**:左下角的时钟按钮,列出最近关闭的 10 个标签页,点一下恢复(保留前进后退记录,放在当前空间);列表底部的「打开完整历史记录」会打开 Chrome 的历史记录页。用的是 Chrome 自己的记录,只包括本次启动以来关闭的,不分空间。
- **休眠**:鼠标移到标签页或开着的固定标签上,点关闭按钮左边的月亮图标;也可以右键标签页、收藏或固定标签选「休眠」,让 Chrome 把它从内存里卸掉(标签还在,点回去会重新加载);休眠正在看的标签页时,会先切回刚才所在的标签页(没有就切到它下面的),和关闭时一样;右键文件夹可以让里面所有标签页一起休眠(包括正在看的),右键空间可以让里面所有不在前台的标签页一起休眠。休眠的标签页(包括重启后还没加载的)显示为变淡,收藏和固定标签也一样;标签页列表和固定标签的行尾还标着休眠了多久(比如「2 小时」),和关掉的固定标签分得开。
- **保持唤醒**:右键选「保持唤醒」,Chrome 的「节省内存」就不会回收这个标签页,适合音乐、聊天这类要在后台一直运行的页面;手动休眠时会顺便取消保持唤醒。这个设置浏览器重启后会恢复。
- **右键菜单**:标签页、收藏/固定项、空间圆点都有,可以复制链接地址、硬性重新加载(不走缓存)、移到别的空间等。
- **复制成 Markdown**:右键空间圆点(或点右上角三个点),把整个空间的标签页复制成「- [标题](链接)」的列表,开头一行是空间名;固定区的文件夹和子标签页按层级缩进,新标签页跳过,收藏不算在内。多选标签页后右键,只复制选中的。用的是网页自己的标题,方便直接贴给 AI。
- **浅色 / 深色模式**:跟随系统。
- **中文 / English**:默认跟随 Chrome 的界面语言(简体中文显示中文,其他显示英文),也可以点右下角的设置按钮(鼠标移到底部时出现)手动选。
