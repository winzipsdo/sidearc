## 商品详情(Store listing)

**名称**:Sidearc(取自 manifest)

**简短说明**(取自 manifest,132 字符以内):

> 把标签页放到侧边栏:垂直排列,支持子标签和空间,常用的固定在顶部。

**详细说明**:

```
Sidearc 把标签页搬到浏览器侧边栏,用更适合宽屏的方式管理它们。

【垂直标签栏】
· 标签页纵向排列,标题不再被挤成一小截
· 拖拽排序,中键关闭,正在发声的标签一键静音
· 顶部搜索栏:输入即过滤标签页,回车直接打开网址或搜索

【和顶部标签栏同步】
· 顶部原生标签栏的顺序始终和侧边栏一致,在哪边拖动都会同步
· 每个空间是顶部的一个标签页分组,切换空间时其他空间自动折叠

【子标签】
· 从某个页面里打开的链接,自动缩进归到它下面
· 把标签页拖到另一个标签页上即可归组,拖出来即可移出
· 关闭父标签时,子标签一并关闭

【收藏夹与固定标签】
· 收藏夹:顶部的图标网格,常用网站一点即达,所有空间共用
· 固定标签:关闭后仍保留入口,再点重新打开
· 固定标签可以分文件夹,折叠起来更清爽
· 固定标签点进别的页面后,一键回到原来的地址

【空间】
· 用空间把工作、学习、生活分开,每个空间有自己的主题色、固定标签和标签页
· 底部圆点一键切换

【少开重复的标签页】
· 打开已经开着的网址时,直接切到那个标签页
· 打开收藏或固定过的网址时,直接用那个收藏或固定标签打开

【别名】
· 给标签页起个自己的名字,显示在标题左侧,搜索也能匹配

【不怕误操作】
· 关闭标签页、清理、取消固定都可以撤销,支持 Ctrl/Cmd+Z 连续撤销,在顶部标签栏关掉的也能恢复
· 底部一键查看最近关闭的标签页,点一下就恢复
· 浏览器重启后,空间、子标签、别名自动恢复

【隐私】
· 不收集任何数据,没有任何网络请求,所有内容只保存在本机
· 开源:https://github.com/winzipsdo/sidearc

使用方法:点击工具栏上的 Sidearc 图标,或按 Alt+S 打开侧边栏。

说明:顶部原生标签栏仍然保留,Sidearc 会让它的顺序和侧边栏保持一致,并把其他空间的标签页折叠起来。
```

**类别**:工具(Tools)或 工作流程与规划(Workflow & Planning)

**语言**:中文(简体)

## 隐私权规范(Privacy practices)

**单一用途说明**:

> 在浏览器侧边栏中以垂直列表的方式显示和管理当前窗口的标签页(排序、分组、固定、命名、关闭与恢复)。

**权限理由**(每项权限都要填):

| 权限 | 理由 |
| --- | --- |
| `sidePanel` | 扩展的全部界面都显示在浏览器侧边栏中。 |
| `tabs` | 读取标签页的标题、网址和图标以在侧边栏中列出,并执行用户发起的切换、移动、关闭、新建操作。 |
| `storage` | 在本地保存用户创建的空间、收藏夹、固定标签、别名,以及用于重启后恢复的标签页状态。 |
| `favicon` | 为收藏夹和固定标签显示对应网站的图标。 |
| `search` | 用户在侧边栏搜索框输入关键词并回车时,用浏览器的默认搜索引擎进行搜索。 |
| `clipboardWrite` | 用户在右键菜单选择「复制链接地址」时,把该标签页的网址写入剪贴板。 |
| `sessions` | 用户撤销「关闭标签页」时,从浏览器的最近关闭记录中恢复该标签页(保留其历史记录)。 |
| `history` | 仅用于「不记录历史」的空间:在该空间里访问的网址被记入历史后立即删除;不读取其他浏览历史。 |
| `webNavigation` | 识别新标签页是否由某个页面里的链接打开,以便把它显示为该页面的子标签;不读取也不保存导航内容。 |
| `tabGroups` | 把用户的每个空间显示为顶部标签栏中的一个标签页分组,并在切换空间时折叠其他空间的分组。 |

**是否使用远程代码**:否。

**数据使用声明**:不勾选任何数据类型(扩展不收集、不传输用户数据),并勾选三项合规声明。
如果审核认为读取标签页网址属于「网络浏览记录」,则勾选该项并说明:仅在本机用于显示标签页列表,不离开设备。

**隐私权政策网址**:

## 重新打包

先把 `manifest.json` 里的 `version` 调高,再运行:

```bash
npm run pack
```

会生成 `dist/sidearc-<版本号>.zip`,只包含扩展运行需要的文件。完整的发版步骤见 README 的「发布新版本」。
