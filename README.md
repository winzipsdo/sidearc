# Sidearc

Arc 风格的 Chrome 侧边标签栏:垂直标签页、收藏夹、固定标签与空间。

基于 Manifest V3 和 `chrome.sidePanel`,纯原生 JS/CSS,无构建步骤、无依赖。

## 功能

- **垂直标签栏**:点击切换,中键或 ✕ 关闭,拖拽排序,正在发声的标签可一键静音。
- **收藏夹**:顶部的图标网格,所有空间共用。把标签页拖进去即可添加。
- **固定标签**:每个空间一组。关闭标签页后固定项仍保留,再点会重新打开。
- **空间**:底部圆点切换,每个空间有自己的主题色、固定标签和标签页。把标签页拖到圆点上可移到别的空间。
- **搜索栏**:输入即过滤;回车跳到第一个匹配项,没有匹配时打开网址或用默认搜索引擎搜索;`Ctrl+回车` 强制新开。
- **清理**:一键关闭当前空间里除当前页以外的未固定标签页。
- **右键菜单**:标签页、收藏/固定项、空间圆点都有。
- 跟随系统的浅色 / 深色模式。

## 安装

1. 打开 `chrome://extensions`,开启右上角的「开发者模式」。
2. 点「加载已解压的扩展程序」,选择本仓库所在文件夹。
3. 点工具栏上的插件图标,或按 `Alt+S` 打开/关闭侧边栏。

需要 Chrome 116 或更高版本。

## 已知限制

- Chrome 不允许扩展隐藏顶部的原生标签栏,切换空间也只是过滤侧边栏里的列表。
- 标签页属于哪个空间、绑定了哪个固定项保存在会话存储里,重启浏览器后会重置;恢复的标签页会归入当前空间。收藏夹、固定标签和空间本身是持久保存的。

## 文件

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展清单 |
| `background.js` | 点击图标开关侧边栏;标签页关闭后清理会话数据 |
| `sidepanel.html` / `.css` / `.js` | 侧边栏界面与全部逻辑 |
| `icons/` | 扩展图标 |
