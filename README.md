# Sidearc

Arc 风格的 Chrome 侧边标签栏:垂直标签页、收藏夹、固定标签与空间。

基于 Manifest V3 和 `chrome.sidePanel`,纯原生 JS/CSS,无构建步骤、无依赖。

## 功能

- **垂直标签栏**:点击切换,中键或 ✕ 关闭,拖拽排序,正在发声的标签可一键静音。
- **子标签**:从某个标签页里打开的新标签页会自动缩进显示在它下面;把标签页拖到另一个标签页上也能让它成为子标签;拖到别处或右键「移出为顶级标签页」即可移出;右键父标签选「解除所有子标签」可一次全部移出。最多两级:从子标签里打开的会和它并列。关闭父标签页会连同它的子标签一起关闭。
- **别名**:双击标签行或右键设置,显示在标题左侧,搜索也会匹配。
- **收藏夹**:顶部的图标网格,所有空间共用。把标签页拖进去即可添加。
- **固定标签**:每个空间一组。关闭标签页后固定项仍保留,再点会重新打开。取消固定后底部会出现「撤销」。
- **空间**:底部圆点切换,每个空间有自己的主题色、固定标签和标签页。把标签页拖到圆点上可移到别的空间。
- **不记录历史的空间**:右键空间圆点开启后,在该空间里访问的网址会立刻从浏览历史中删除。这不是无痕模式:Cookie、登录状态、缓存和下载记录照常保留。
- **搜索栏**:输入即过滤;回车跳到第一个匹配项,没有匹配时打开网址或用默认搜索引擎搜索;`Ctrl+回车`(Mac 上是 `⌘+回车`)强制新开。
- **相同地址只开一份**:新开的标签页如果和本窗口里已有的标签页地址相同(忽略 `#` 锚点),会直接切到已有的那个并关掉新开的,可撤销。Chrome 自带的「复制标签页」和恢复关闭的标签页不受影响。
- **清理**:一键关闭当前空间里除当前页以外的未固定标签页,可撤销。
- **关闭下方所有标签页**:右键标签页,关闭列表里排在它下面的所有标签页,可撤销。
- **复制链接地址**:右键标签页或固定项,把网址复制到剪贴板。
- **撤销**:关闭标签页、清理、关闭下方所有标签页、取消固定之后,可以点底部提示条的「撤销」,或在侧边栏里按 `Ctrl+Z`(Mac 上是 `⌘+Z`),可连续撤销多步。
- **从 Arc 导入**:空间菜单里选「从 Arc 导入…」,选择 Arc 的 `StorableSidebar.json`,即可导入收藏夹、各空间的固定标签和打开的标签页。Windows 上该文件在 `%LOCALAPPDATA%\Packages\TheBrowserCompany.Arc_*\LocalCache\Local\Arc\`,macOS 上在 `~/Library/Application Support/Arc/`。
- **右键菜单**:标签页、收藏/固定项、空间圆点都有。
- 跟随系统的浅色 / 深色模式。

## 安装

1. 打开 `chrome://extensions`,开启右上角的「开发者模式」。
2. 点「加载已解压的扩展程序」,选择本仓库所在文件夹。
3. 点工具栏上的插件图标,或按 `Alt+S`(Mac 上是 `⌥ Option+S`)打开/关闭侧边栏。

需要 Chrome 116 或更高版本。

### 把侧边栏放到左边

Chrome 的侧边栏默认在右侧。想让它像 Arc 一样在左边,打开 `chrome://settings/appearance`(设置 → 外观),把「侧边栏位置」改为「显示在左侧」。这是 Chrome 自己的设置,对所有侧边栏生效,扩展无法代为修改。

## 快捷键与操作

| 操作 | Windows / Linux | Mac |
| --- | --- | --- |
| 打开 / 关闭侧边栏 | `Alt+S` | `⌥ Option+S` |
| 撤销(焦点在侧边栏时) | `Ctrl+Z` | `⌘+Z` |
| 搜索栏:跳过匹配项,直接打开网址或搜索 | `Ctrl+回车` | `⌘+回车` |
| 搜索栏:清空 | `Esc` | `Esc` |
| 右键菜单 | 鼠标右键 | 鼠标右键、`Control+点按` 或触控板双指点按 |
| 关闭标签页 | 鼠标中键或 ✕ | 鼠标中键或 ✕(触控板没有中键,用 ✕) |
| 重新打开刚关闭的标签页(Chrome 自带) | `Ctrl+Shift+T` | `⌘+Shift+T` |

打开侧边栏的快捷键可以在 `chrome://extensions/shortcuts` 里修改;如果它和别的扩展或系统快捷键冲突,Chrome 可能不会自动分配,需要在那里手动设置。

## 已知限制

- Chrome 不允许扩展隐藏顶部的原生标签栏,切换空间也只是过滤侧边栏里的列表。
- 标签页的空间归属、父子关系、别名和固定绑定,在浏览器重启或扩展重新加载后会按网址和位置重新对上。前提是 Chrome 启动时恢复了上次的标签页(设置 → 启动时 →「继续浏览上次打开的网页」);没有恢复出来的标签页,数据也就无从恢复。
- 「不记录历史」是按网址删除的:同一个网址在别的空间留下的历史也会一起消失;最近关闭的标签页(`Ctrl+Shift+T`,Mac 上是 `⌘+Shift+T`)里仍能找到。

## 文件

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展清单 |
| `background.js` | 点击图标开关侧边栏;子标签归属;标签页关闭后的清理;重启后的数据恢复 |
| `sidepanel.html` / `.css` / `.js` | 侧边栏界面与全部逻辑 |
| `icons/` | 扩展图标 |
